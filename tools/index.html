Tools

Benches for work already on this site: software, film, illustration, organization. Each one leaves a record you can reuse.

A tool is useful when it produces evidence someone else can read, reuse, or build from.

Each bench is a small state machine: enter the material, shape a local record, export when it is useful. Nothing is sent anywhere. Source goes to the parser. A year mix goes to the ledger. A character goes to the sheet. A prompt goes to depiction. A table goes to RPG Wednesday.

a practice needs a bench that leaves evidence, not a résumé form that asks for a title.

Use this when

you have source, a year mix, a character, a prompt packet, or a sprint you can count.

ASTs, year-mix shapes, playable cards, depiction packets, screenshots, and JSON you can move.

#>integration_loops

Integration loops

Tools are more interesting when they participate in a loop across the site — not when they sit alone as forms. These paths are written for returning readers who want novelty through depth, not through a feature count.

Identity → play → proof

Start in profile or character sheet, test the same role language in RPG Wednesday, leave a card someone can screenshot without a live demo.

Line → image → scene

Draw or tune a mark in SVG experiments, carry palette and stroke reasons into Midjourney bench, attach the result to a recipe card or cast note.

State → gesture → gather

Prototype a hover, hold, or charge behavior in CSS experiments, then test whether it reads on a long route with living terms and the footer cauldron.

Year mix → pantry → table

Name income × skill × expectation in year mix, translate the same constraint into a recipe list or an RPG trade, debrief in session notes.

Source → tree → app

Write literal source in the Spw parser, inspect the tokens and AST, then carry that exact source into the installed app or open a local .spw file there.

Profile Tools

For people naming work that already has rooms: software, film, illustration, design, oration, organization. A collaborator can read the card. A hiring screen can too, if that is the job this week. The years on About are the timing.

  • ^ profile builder Fill in fields, get a configurable card with header, badges, sections, and footer. Copy as JSON or Spw seed. Screenshot for sharing. Local-only, no account needed.
  • @ character sheet builder Start from a character sheet. Carry party role, quest, and signal items into play, film, and illustration language.
  • ^ services card A pre-configured seed card for describing services and rates. From the services page.
  • ~ ask card A card for personal asks — supplies, food, bills. The same aesthetic makes a personal need feel as intentional as a professional offer, which matters when your network includes mentors, peers, and future collaborators.
~"card_tools"

Seed Cards

Seed cards are minimal vessels — fill in, copy, screenshot, share. Templates: new year, session, wonder, services, ask. They travel to a collaborator, a table, or a later-you still learning the vocabulary. Each card can hold anchors, term clusters, component kinds, and settings notes.

  • ^ new year card Annual threshold card — vow, bundle, relay, revisit. For the moment when time feels writable again.
  • @ session card Date, scene, turn, carry, revisit. For documenting what happened at the table.
  • ?[ wonder card Question, tension, material, relay, revisit. For open questions you're genuinely uncertain about.
  • @ spell ingredient card Anchor, cluster, component, setting, attribute, event. For turning a strange idea into a reusable semantic recipe.
@"play_tools"

Play Tools

Character sheets are practice for oration and film as much as for a profile. Naming a role, a pressure, and a next arc is the same muscle as writing a shot, a scene, or a public card. RPG Wednesday is the recurring table. The builder carries that grammar into play, depiction, and the 2027 movie.

  • @ rpg wednesday The recurring session — character cards, local gameplay state, session logs, and the character 'l'n'd'r as a profile specimen.
  • @ session log Dated event log. Use the session seed card template to document plays.
  • ~ character sheet builder Build a local character sheet that maps party role, tools, quest, and world state into a card a table, illustrator, or film surface can hold.
  • ~ midjourney bench Keep style refs, omni refs, shotboards, and collaborator-aware image experiments in a route that can expand later.
