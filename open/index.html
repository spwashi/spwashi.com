Open a Spw document

A .spw file opens here as a room. Parsing stays in this browser. Double-click on desktop Chromium, share into the installed app, or choose a file. The text is not uploaded.

Named blocks such as ^"seed", ^"clusters", ^"bridges", ^"operators", and ^"queries" become the room. Anything else stays in the source. A handoff between pages uses sessionStorage and is cleared when this page reads it. A system share waits in Cache Storage as spw-document-share until this page reads it and deletes it. Installed file association is a desktop Chromium feature. Other browsers use the file field.
