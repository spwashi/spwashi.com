Forms, side by side

Lines that differ in one thing, and what that thing does. Each opens in the editor or on the pivot.

how a body holds its parts · which wall a word sits in · a mark in front · where a mark sits · two lines joined · a line or a file · samples

How a body holds its parts

  1. garden{seed.water}One name. The dot keeps seed.water whole, as a path names one thing.edit pivot
  2. garden{seed, water}Held together. Both are there at once, and their order says nothing.edit pivot
  3. garden{seed; water}In order. Seed comes first, and the order is part of what it says.edit pivot
  4. garden{seed ~> water}A path. Seed is carried on to water, and the two stay two.edit pivot

Which wall a word sits in

  1. garden[care]The lens: the garden, read through care.edit pivot
  2. garden{care}What it holds: care is inside the garden.edit pivot
  3. garden(care)The scene: the garden where care is.edit pivot
  4. garden<care>Where it goes: the garden, toward care.edit pivot
  5. garden[care]{seed}(spring)<harvest>All four read as one sentence: the garden, through care, holding seed, in spring, toward harvest.edit pivot

A mark in front

  1. ?gardenA question about the garden, one you can close again.edit pivot
  2. !gardenA move made on the garden, so its consequence can be seen.edit pivot
  3. ~gardenA way toward the garden, kept open and not taken.edit pivot
  4. *gardenThe garden as what carries weight here.edit pivot
  5. .gardenThe garden as it stands by default.edit pivot

Where a mark sits

  1. ?garden{seed}In front of the word, the question takes in the whole line.edit pivot
  2. garden{?seed}Inside the braces, it asks about the seed alone.edit pivot

Two lines joined

  1. garden ~ harvestFrom the garden, the harvest follows.edit pivot
  2. garden & harvestThe harvest is what the garden is about.edit pivot
  3. garden ^ harvestBoth lifted into one relation you can look at.edit pivot
  4. gardener @ gardenThe garden, as the gardener sees it.edit pivot

A line, or a file

garden[care]{seed; water; harvest}
garden[care]{
  seed;
  water;
  harvest
}

The same line, chopped down. It reads the same; a file earns its lines once a part grows braces of its own. Edit the file
