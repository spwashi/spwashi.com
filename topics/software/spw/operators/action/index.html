! Action

The action operator commits an addressed intention. It is not generic clickability; it is the moment a selected posture becomes consequence. On this site, it marks where work becomes visible enough to act on.

Returning learners can treat this as the current action anchor and the handoff point from inquiry to consequence.

Interaction

Commit a local action or projection. If action is unavailable, the interface should state what precondition is missing.

Metaphysics

Action is attention taking a position. It turns observation into force while staying accountable to the current frame.

Brace Physics

An action discharges stored brace charge. The release should be visible as navigation, projection, or a changed inspectable register.

Symmetry

Prefix !x primes the next unit as a committing move. Postfix x! marks that the unit has been acted through. Use @x only when you mean perspective — situating the viewpoint, not forcing consequence.
