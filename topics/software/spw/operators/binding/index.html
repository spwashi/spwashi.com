= Binding

The binding operator gives a local value a name. That name can be reused, compared, and released.

previous: & merge ~operator_atlas next: $ meta
^"binding_contract"{

Contract

In hand

Name, pin, or categorize a value. The name stays inspectable, and it can be released.

What it means

The mark is attention agreeing to a stable name. The name and the thing keep pointing at each other.

Brace Physics

The brace stores the name on the boundary. A binding you cannot inspect is pressure without an address.

Before and after

Prefix =x primes a value for naming. Postfix x= marks the value as bound after it resolves.
