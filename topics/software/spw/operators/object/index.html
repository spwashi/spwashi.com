Spw Operator

^ Object

The object operator lifts material into structured content. It turns a readable passage into a block that tools can inspect without hiding the text. Read this page when you need a structured block to stay visibly connected to the draft it came from.

Returning learners can use this as the current anchor for lifted content, inspectable blocks, and the difference between raw passage and structured object.

Object is elevation: attention rises from raw perception into a named structure that can hold consequence.

Brace Physics

An object condenses charge into block depth. The brace opens, then the block stores what was found inside.
