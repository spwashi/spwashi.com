!"spell_ingredients"

Spells can be semantic recipes, not only UI effects.

A spell is a compact way to say what should travel: a route anchor, a cluster of terms, a component kind, a settings state, and the data attributes that make the result inspectable. That gives the whimsy marketing value because it also gives engineers and language models usable structure.

Anchor spell

#search-rediscovery + #spell-ingredients preserves where a thought should return.

Cluster spell

substrate + arc + conduit + proof turns vocabulary into a routeable prompt packet.

Component spell

site-frame / frame-panel / operator-chip names the kind of object a designer or engineer should produce.

Settings spell

semantic-density + enhancement-level + utility visibility records the reading climate for a screenshot or session.

Attribute spell

data-spw-role + data-spw-feature + data-spw-semantic-expression lets a page explain what it is doing.

Event spell

curiosity -> artifact -> return path connects play, publishing, and community without flattening the magic.
