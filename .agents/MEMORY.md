## Cross-agent misses (added 2026-09-04 — verified in-session, not carried over from another agent's report)

- **Concurrent sessions share this working tree.** Multiple agents (Claude, Grok, others) commit straight to `main` in overlapping windows. Never `git stash` here — a concurrent session's uncommitted work isn't yours to shelve. Check `git log`/`git status` before assuming a regression is yours; it may be a sibling session's commit that landed mid-turn. Foundational shared files (`components/surfaces.css`, module-catalog defs, `AGENTS.md`) are the highest-collision-risk targets — expect them to move under you.
- **Commit format is load-bearing, not decorative.** Subject: `symbol[category] short claim`. Body closes with exactly one `#[episode]{ ~[scene]{} ![change]{} *[verify]{} }`. `npm run check:local` does not validate this grammar — nothing else will catch a malformed one. Full grammar: `.agents/plans/history-reflow/PLAN.md`.
- **A catalog/CSS selector citing an old class name is a silent-failure class, not a syntax error.** `.site-frame` → `.spw-frame` (landed `b0a04492`) left six `MODULE_DEFS` selectors and dozens of live-route class attributes stale for weeks — nothing errored, the modules just never mounted. Before trusting any selector string (JS catalog or CSS), grep the actual current HTML for what it claims to match; don't assume a rename propagated everywhere it was cited. `npm run audit:module-selectors` catches the catalog half of this; it does not catch build-time `<spw-include>` partials (source-only scan — see `.spw/audits/module-selector-depth-2026-09.spw`'s `scanner_false_positive` note before calling something orphaned).
- **A green check is not proof a fix works.** `contain: paint` + an identity `transform` on `.frame-panel` looked like it explained an intermittent blank-render bug; it didn't — live, repeated, fresh-tab trials (not a single screenshot) were what actually disproved it. Prefer reproducing or disproving a claim in a real browser over reasoning from source alone when the question is "does this actually render/behave correctly."
- **Pacing, motion-feel, and sensation decisions get a human demo before landing**, not just a passing test suite — this is a taste call, not a correctness one.
- **`grep`-ing literal `data-spw-*` strings misses `el.dataset.spwFooBar =` writers.** Check both forms before claiming "nothing writes this attribute."
- **A components-layer `:where(button)` 2.75rem floor beats shell compact chrome.** `check:local` stays green. Pocket travel rails (`[data-spw-floating-chrome]`, `.spw-section-handle-shell`) keep `--touch-target-compact`. The `spw-craft-quality` table used to say “44px on every coarse button in components/*.css” — that is the instruction Claude/Codex followed. Open `.spw/caches/touch-control-class-2026-09.spw`.
- **An audit P1 list is not a patch list.** Compact tokens and `* 0.75` restatements in later layers are packing altitude. Unifying TOUCH / GESTURE / progression selectors makes inspect lie.
- **A generated plan `index.spw` that passes `plans:index:check` can still be thinner than the hand-authored file** (noise tokens, empty research_bridge, truncated scope). Compare before swapping. Passing validation is not the richness bar. Origin: Claude session 9ba112ec, commit `239bca44`.
- **User “don’t verify the visuals” is a finding, not a waiver.** Codex 01a0780b skipped `visual:checks` while landing teardown next to an uncommitted CSS bundle from a sibling session. Still do not steal pocket chrome. `visual:checks` remains the instrument when ink or floating chrome moved.
- **Agent markdown spend:** Always-on context is I/O, not thinking. `npm run check:agents` fails if `AGENTS.md`, MEMORY, an adapter, or the agent-optimization gate exceeds its word budget. The 12k optimization diary lives at `.agents/plans/archive/2026-09-06-agent-optimization-diary.md`. Team-orientation copy dump is archived, not in the active plan tree. Census: `.spw/caches/agent-markdown-spend-2026-09.spw`. Do not rewrite AGENTS from a cache. Do not apply AI onto a diary PLAN as if that were the process.
