# Editorial readability

Operation: align. Fixity: tending.

Public goal: make paragraphs, lists, and definitions easier to understand across the site while preserving the creator's voice and existing routes.

This pass edits Home, About, Services, and Membership HTML copy. It makes first actions explicit, breaks dense offers into clear clauses, and defines destination routes in plain language. Shared typography adds modest spacing for adjacent paragraphs, multi-paragraph list items, and definition groups. Future route passes can follow the same pattern without changing page structure or adding a copy system.

A later pass that meets a link-dense paragraph follows `.agents/plans/semantic-copy-depth/PLAN.md`, section "Thought trace". A paragraph whose links are the point is a display case and belongs in a list or a `data-spw-copy-depth="dense"` sibling. Home's field note that begins "recursive editorial loop" is that shape and waits; this plan does not open it. The smell constraints on the rewrite are `.spw/caches/ai-writing-smells-2026-09.spw`.

Validate with the copy accessor audit, generated manifest, CSS build, site check, local check, and `git diff --check`.
