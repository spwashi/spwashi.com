## Theory examined
Workbench `form-geometry.spw` distinguishes invertible surface edits from semantic
equivalence. `form-geometry-editor` requires source-specific receipts and a thin
client. `symmetry-explorer-instrument` proposes D4 on a square. Use these as
constraints for a site experiment, not evidence that Spw meanings form D4.

HTML supplies address and containment; CSS supplies a response law; JS supplies
state transitions; `.spw` supplies claims and probes. Metamaterial is useful for
composition-dependent response. A labeled graph with local response rules is more
precise for navigation. No new parser grammar, physics simulation, or dependencies.
