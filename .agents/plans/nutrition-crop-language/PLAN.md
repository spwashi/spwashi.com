# Nutrition Crop Language

## Goal
Update the public copy across the site so vegetables read as dimensional objects with relationships, not just ingredients. The site should wonder about size, shape, density, storage, seasonality, adjacency, and the way one crop changes the rest of the plate or garden.

## Scope
- Home: revise the main editorial loop so the site’s cooking metaphor explicitly includes vegetable form and relational thinking.
- Play: let RPG Wednesday and the broader play hub treat vegetables as a shared rules surface for timing, trade, and table pressure.
- Recipes: sharpen the kitchen copy so crops, cuts, and neighbor ingredients read as teachable dimensions.
- About: keep the creator-identity framing while making the food language more reflective of vegetables as systems.

## Constraints
- Keep the edits surgical and route-local.
- Preserve the current hand-authored HTML structure, links, and metadata unless the wording itself needs to shift.
- Avoid inventing a new taxonomy; reuse the site’s existing crop, pantry, garden, and relationship vocabulary.

## Validation
- `git diff --check`
- Targeted `rg` review for the updated phrases and any accidental copy drift.
- Basic surrounding-markup scan for balanced tags on each edited route.
