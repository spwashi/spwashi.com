Design / Ornament

Ornament Map

An ornament is the visual projection of the attention field. It does not invent a meaning; it shows one that is already there: which operator this is, whether it is warm right now, whether you collected it, whether a setting has drifted. This page maps every mark you can author to the sheet that paints it and the rule that says when it may.

Meet the map once and this session treats it as familiar.

Ornament arrives after first paint with the flourish pack, so nothing on this page may move, hide, or resize structure when it lands. Read a mark here, then find it in the wild: corners in the spectral workshop and the staged theme sets, braces in the parser’s specimen suite, or any frame topline. Each link lands on the room itself, not the top of the page.

Three altitudes, one mark

Semantic state is authored in HTML. Field state is written by the runtime as attention moves. Ornament reads both and paints. A mark that reads only the first is a label; a mark that reads only the second is fog.

Corner

Four ticks at the corners of a frame or panel. They spend the host's attention light and retreat when the host is dimmed, so a lit frame reads as held and a dimmed one as set down. Zero flow: they move nothing when they arrive.

Visited, collected, deviated

Three marks that must stay distinct: a visited surface takes a ◈ stamp; a collected term takes a hard floor mark that does not decay; a deviated setting takes a quieter third glyph near its control. If all three only brightened teal, the field model would fail its own legibility test.

Site rhythm, holidays, whimsy

data-spw-ornament="site-rhythm" paces ornament to the site tempo. Holiday tropes idle with the flourish pack and never enter core. Whimsy is the quiet interaction grammar of sigils and folds: alignment, focus, revealed structure, no decorative motion.

?[may_it]

Four questions before a new mark

  1. Which altitude does it read? Semantic, field, or both. A mark that reads neither is decoration, and the wonder doctrine already refuses it.
  2. Does it move anything when it arrives? Ornament idle-loads. If first paint would be wrong without it, it is structure and belongs in a components sheet.
  3. Is it calm at rest? Resonance, charge, and attention may lift it. Nothing else should.
  4. Which existing stem carries it? data-spw-ornament, data-spw-accent, data-spw-texture-slice, or a class. A fourth family is a refusal.
