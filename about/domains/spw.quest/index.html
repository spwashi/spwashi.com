spw.quest

spw.quest opens with a guide to the Spw language: one page to read, the twelve sigils and their couple, and the four brace pairs. This page is the guide beside it: constructs you can reuse, sensors you should run, and grammar you should not fork.

The install page puts the Spw Workbench into a repository. You choose who runs the setup, copy one block, run it from the repository root, and doctor tells you it worked. It stops before any commit.
