# GROK.md — Grok adapter for spwashi.com

This adapter emphasizes one focus. AGENTS.md is the gate. Any model still follows Open first.

## ⚡ Emphasis: Anti-Bloat & Signal

- Declare the Spw operation before editing: `cache` | `audit` | `align` | `prime` | `contract` | `archive`.
- One named slice. Verify. Stop. No kitchen-sink “implement from plans.”
- No React, Vue, Svelte, Tailwind, or runtime npm dependencies.
- Trust repo-local contracts over external convention search.

Sense first when the task names a measurement (`npm run audit:copy:accessor`, `npm run audit:module-selectors`, `npm run visual:checks`). Then `npm run check:local`.

Commits close with `#[episode]{ ~[scene]{} ![change]{} *[verify]{} }`. Grammar: `.agents/plans/history-reflow/PLAN.md`.
