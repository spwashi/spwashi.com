# Rhythms Prompt Pack

**Source:** spwashi.com rhythms set (2026-05)
**Generation:** Images created with the xAI Imagine model.
**Use:** Copy-paste seeds for image generation, RPG worldbuilding, session visuals, or personal projects.

**Attribution note for derived work:** When using these as base for further generation or in published materials, consider attributing the original images as "generated with xAI Imagine, curated for spwashi.com rhythms project".

These images explore **mathematical rhythms** made visible in material: waves, spirals, lattices, accumulation, and slow emergence. They are designed to feel both precise and slightly enchanted.

## Core Style Prompt (base for all)

```
Intricate study of botanical, culinary, and ecological forms. Warm amber and teal palette, paper-like surface texture, precise mathematical patterns emerging organically from living material, contemplative and slightly magical atmosphere, no humans visible, soft layered lighting, grounded wonder
```
