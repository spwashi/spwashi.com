spwashi.com

I'm Spwashi. This site is where I publish: more than two hundred routes written by hand in HTML and CSS, readable before any script runs. It is where I publish, and the pages are the work.

How it works

Styles sit in named cascade layers, reset and tokens through shell, grammar, components, systems, handles, effects and ornament, with routes, modes and themes in their own folders: 213 stylesheets you can open and read. JavaScript, 311 files of it, arrives only when HTML and CSS cannot carry a behavior. Beside the pages, 923 .spw files describe how the parts behave, and a set of checks runs before any change lands.

Touch it live

You are already inside it. The website field guide names its parts; the source is public on GitHub. Turn JavaScript off and the words stay.

The working rule the repository gives agent sessions editing it: "Sense first, one named patch, stop."

What came before

Before this site came frameworks: PHP and JavaScript ones written from scratch in 2017–2019, then a React codebase that ran from 2021 to 2023. This site keeps none of them. Its nearest kin are small static sites: tealstripesvibes.com in early 2024, then spwashi.click, built with plain modules and cascade layers, and spwashi.work, both from one weekend in 2026. The whole line is on the projects hub.

What it keeps teaching

Three lines from the field guide, each one learned by keeping this site running.

  • “The sentence should already hold.” A page reads before any chip, lens, or script adds to it.
  • “Make a page. It does not need to begin as a studio.” The field guide's advice to anyone starting a site of their own.
  • “Measure, then claim.” Every performance number on the field guide can be recomputed from the repository, and so can every number on this page.
